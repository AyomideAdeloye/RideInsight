# RideInsight

RideInsight is a vehicle-focused social platform where users share builds, compare vehicles, and track modifications.

## Features
- 🚗 Social feed (posts, images, likes)
- 🔍 Filter posts by vehicle
- 🧰 Garage system (add vehicles)
- 🛠️ Build tracking (mods + cost)
- 💰 Automatic total build cost per vehicle

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python)
- Database: SQLite

## Future Improvements
- User authentication
- Image uploads (not just URLs)
- Comments system
- Vehicle comparison engine
- Mobile app version
